# Capturas de pantalla

Esta carpeta está pensada para guardar capturas reales de la aplicación
en ejecución (útiles para el README y para la presentación).

Este proyecto fue generado y validado en un entorno de desarrollo sin
navegador gráfico disponible, así que las capturas no se generaron
automáticamente. La aplicación sí fue probada de extremo a extremo con
`streamlit.testing.v1.AppTest` (carga inicial, filtros, y los dos
botones del simulador), confirmando que corre sin errores.

Para generar tus propias capturas antes de la presentación:

1. Ejecuta la app: `streamlit run app.py`
2. Ábrela en `http://localhost:8501`
3. Toma capturas de:
   - `dashboard_general.png` — pestaña "Dashboard General"
   - `jugador_individual.png` — pestaña "Jugador Individual" con un jugador seleccionado
   - `alertas.png` — pestaña "Alertas Inteligentes"
   - `panel_ejecutivo.png` — pestaña "Panel Ejecutivo"
4. Guárdalas en esta carpeta con esos nombres; el README ya las referencia.
